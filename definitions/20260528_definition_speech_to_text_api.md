# Speech-to-Text API

## Definition

A speech-to-text API is a service interface that accepts audio input and returns
written text. The input can be a local file, uploaded file, URL, stream, or
encoded audio payload, depending on the provider.

## Context and Usage

Development teams use speech-to-text APIs to turn meetings, demos, interviews,
support calls, and product walkthroughs into searchable records. A transcription
workflow often pairs the API with media conversion, batching, retry handling,
and transcript review so the output can be reused in tickets, documentation,
summaries, and knowledge bases.
